# 1.0.0

First release of Scannable Reforged — a NeoForge 1.21.1 port and fork of Scannable by Florian "Sangar" Nücke.

- Ported to Minecraft 1.21.1 / NeoForge (original targets up to 1.20.4).
- **New:** Spawner Scanner Module (`scannable:spawner_module`) — scans for nearby mob spawners.
- Increased scanner FE capacity (5,000 → 20,000).
- Retains the original Scannable feature set and MIT license (credit: Florian "Sangar" Nücke / MightyPirates).
- Verified against a large modded pack and Iris/Sodium shaders.
